# Wafer Map Defect Pattern Classification with Explainable AI

## 프로젝트 소개

본 프로젝트는 반도체 제조 공정에서 발생하는 웨이퍼 맵 결함 패턴을 머신러닝 및 딥러닝 모델로 분류하고, Grad-CAM 기반 해석 가능한 AI 기법을 활용하여 모델의 판단 근거를 시각화하는 것을 목표로 한다.

최근 AI 반도체와 HBM(High Bandwidth Memory)에 대한 수요가 증가하면서, 반도체 제조 공정에서 수율(Yield) 관리와 결함 분석의 중요성이 더욱 커지고 있다. 특히 HBM과 같은 첨단 반도체 제품은 공정 및 패키징 난이도가 높기 때문에, 제조 과정에서 발생하는 결함을 빠르게 탐지하고 원인을 분석하는 기술이 중요하다.

본 프로젝트에서는 실제 HBM 제조 데이터가 공개되어 있지 않다는 한계를 고려하여, 공개 데이터셋인 WM-811K Wafer Map Dataset을 활용한다. 이를 통해 웨이퍼 맵 기반 결함 패턴 분류 모델을 구현하고, 클래스 불균형 문제와 모델 해석 가능성을 함께 분석한다.

---

## 프로젝트 주제

**HBM 수율 개선을 위한 웨이퍼 맵 결함 패턴 분류 및 해석 가능한 AI 분석**

보다 정확하게는 다음과 같은 연구 방향을 가진다.

> 공개 웨이퍼 맵 데이터셋을 활용하여 결함 유형을 자동 분류하고, Grad-CAM을 통해 모델이 결함 판단 시 주목한 영역을 시각화함으로써 첨단 반도체 수율 관리에 활용 가능한 AI 기반 결함 분석 방법을 탐색한다.

---

## 연구 배경

반도체 제조 공정에서는 하나의 웨이퍼 위에 수많은 die가 형성된다. 제조 후 각 die는 정상 또는 불량으로 판정되며, 이러한 결과는 웨이퍼 맵 형태로 표현된다.

웨이퍼 맵의 결함 분포는 단순한 불량 위치 정보가 아니라, 공정 이상이나 장비 문제를 추정할 수 있는 중요한 단서가 될 수 있다. 예를 들어 특정 결함이 웨이퍼 가장자리에 집중되거나, 중앙부에 몰리거나, 선형으로 나타나는 경우 각각 다른 공정 문제를 암시할 수 있다.

따라서 웨이퍼 맵 결함 패턴을 자동으로 분류하는 모델은 반도체 수율 저하 원인 분석과 품질 관리에 활용될 가능성이 있다.

## 연구 질문

본 프로젝트의 주요 연구 질문은 다음과 같다.

1. 웨이퍼 맵의 불량 분포 패턴을 기반으로 결함 유형을 자동 분류할 수 있는가?
2. 클래스 불균형이 심한 웨이퍼 맵 데이터에서 단순 Accuracy가 아닌 클래스별 성능을 어떻게 평가할 수 있는가?
3. 클래스 불균형 처리 기법이 소수 결함 클래스의 분류 성능을 개선하는가?
4. Grad-CAM을 활용했을 때 모델이 실제 결함 영역을 근거로 판단하는지 시각적으로 확인할 수 있는가?
5. 웨이퍼 맵 기반 결함 분류 모델이 첨단 반도체 수율 관리 관점에서 어떤 의미를 가질 수 있는가?

## 사용 데이터셋

### WM-811K Wafer Map Dataset

본 프로젝트에서는 Kaggle에 공개된 WM-811K Wafer Map Dataset을 사용한다.

이 데이터셋은 반도체 웨이퍼 맵 데이터를 포함하며, 각 웨이퍼 맵은 die 단위의 정상/불량 정보를 2차원 배열 형태로 나타낸다.

### 주요 결함 클래스

WM-811K 데이터셋에서 다루는 대표적인 결함 유형은 다음과 같다.

| 클래스 | 설명 |
|---|---|
| none | 특별한 결함 패턴이 없는 정상 또는 무결함 웨이퍼 |
| Center | 웨이퍼 중앙부에 결함이 집중된 패턴 |
| Donut | 도넛 형태로 결함이 분포하는 패턴 |
| Edge-Loc | 웨이퍼 가장자리 특정 위치에 결함이 집중된 패턴 |
| Edge-Ring | 웨이퍼 가장자리를 따라 링 형태로 결함이 나타나는 패턴 |
| Loc | 특정 국소 영역에 결함이 집중된 패턴 |
| Random | 결함이 무작위로 분포하는 패턴 |
| Scratch | 긁힘처럼 선형으로 결함이 나타나는 패턴 |
| Near-full | 웨이퍼 대부분이 불량에 가까운 패턴 |
